# Données transport et RH, coûts et CO2 – Excel

**Outil** : Excel · **Projet 3** · Les Couturiers Inclusifs

**Objectif** : fiabiliser les données du TMS pour réduire les coûts de transport et l'empreinte carbone, dans le respect du RGPD.

**Démarche**
- Procédure de collecte et de nettoyage : données source intactes, minimisation, modifications consignées
- Minimisation RGPD : le numéro de sécurité sociale réduit au genre et à l'année de naissance
- Tableaux de bord RH et transport (cumul 9 mois, 2021 vs 2022)

**Recommandations**
- Tester le groupage pour réduire les distances
- Relancer AFF dans le mix transport
- Renégocier les tarifs PAEX et POLE
- Suivre le CO2 par km avec un seuil d'alerte

**Compétences** : règles de nettoyage, collecte conforme au RGPD, pré-traitement des données
